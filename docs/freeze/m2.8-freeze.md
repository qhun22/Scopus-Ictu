## Capability chain

Frozen capability chain:

`APPROVED lecturer–Scopus identity → read projection/query layer → role-safe read API → lecturer profile UI → approved identity UI → lecturer publications UI`

The implementation contract supports:

- `APPROVED` identities only
- multiple `APPROVED` identities for one lecturer
- canonical publication deduplication by `publications.eid`
- deterministic publication order
- backend-driven pagination
- aggregates over the full deduplicated result set
- safe lecturer-facing evidence fields only
- preserved `NULL` citation semantics
- preserved `NULL` publication-year semantics

## Authorization

- `LECTURER`: own linked lecturer only, resolved server-side from
  `current_user.lecturer_id`; cannot select another lecturer ID.
- `ADMIN`: explicit target endpoints only.
- `REVIEWER`: no general lecturer Scopus profile access.
- Unauthenticated requests: denied.

Frontend self-service routes `/profile`, `/identity`, and
`/my-publications` are `LECTURER`-only.

## API contract

Lecturer self-service read endpoints:

- `GET /api/v1/lecturers/me/profile`
- `GET /api/v1/lecturers/me/identities`
- `GET /api/v1/lecturers/me/publications?page=&page_size=`

ADMIN explicit-target read endpoints:

- `GET /api/v1/lecturers/{lecturer_id}/scopus/profile`
- `GET /api/v1/lecturers/{lecturer_id}/scopus/identities`
- `GET /api/v1/lecturers/{lecturer_id}/scopus/publications?page=&page_size=`

All endpoints are read-only. None performs matching, candidate scoring, review
decisions, crawler execution, live Scopus lookup, or identity mutation.

## Data semantics

- Approved identity status: `APPROVED`
- Canonical publication key: `publications.eid`
- Publication order: `year DESC NULLS LAST`, then `eid ASC`
- `cited_by_count IS NULL`: citation data is unknown.
- `cited_by_count == 0`: citation data is known and the count is zero.
- `year IS NULL`: publication year is unknown.

Publication aggregate fields:

- `total_publications`
- `publication_count_by_year`
- `unknown_year_count`
- `known_citation_sum`
- `citation_unknown_publication_count`
- `approved_identity_count`

Aggregates apply to the full deduplicated publication result set, not only the
current page.

## Safe evidence

Lecturer-facing evidence fields are limited to:

- `evidence_type`
- `direction`
- `created_at`

The lecturer projection does not expose `features`, `algorithm_version`,
`evidence_fingerprint`, `source_refs`, `confidence_score`, or audit internals.
`confidence_score` is not presented as reviewer confidence.
