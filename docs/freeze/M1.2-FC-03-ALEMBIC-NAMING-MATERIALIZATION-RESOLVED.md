# M1.2-FC-03 — ALEMBIC NAMING MATERIALIZATION

Status: RESOLVED / FROZEN

The frozen SQLAlchemy naming convention remains unchanged.

Names already materialized from Base.metadata are represented in
Alembic migration operations with `op.f(...)` to prevent naming
convention reapplication.

PostgreSQL identifiers longer than 63 characters are not manually
renamed. SQLAlchemy's deterministic dialect truncation/hash is the
authoritative physical catalog materialization.

Logical FK:

fk_scopus_author_name_variants_first_seen_raw_record_id_raw_scopus_records

PostgreSQL rendered FK:

fk_scopus_author_name_variants_first_seen_raw_record_id_d3c5

No schema semantics are changed by FC-03.
